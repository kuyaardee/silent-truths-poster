Privacy Policy

Silent Truths Poster · Last updated 6 November 2026

Silent Truths Poster ("the tool") is a private script used only by the owner of the SilentTruths YouTube channel to publish that channel's own videos. This policy explains what information the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using it, the owner is also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Information the tool accesses

  • The owner's own Google authorization. When the owner signs in, Google issues an access token for uploading to and reading the owner's own channel (scopes: youtube.upload, youtube.readonly).
  • The owner's own channel information. The channel ID and the titles and IDs of the channel's own uploads, used only to confirm that a newly uploaded video is live.

The tool does not access any other user's data, does not collect information about viewers, and has no users other than the channel owner.

Facebook Page posting

After a video is published, the tool posts an image, a caption and a link to the video on the owner's own Facebook Page (Silent Truths), using a Page access token for that Page only (permissions: pages_show_list, pages_read_engagement, pages_manage_posts). It does not read or collect information about other people, followers or comments. The token is stored only on the owner's computer, and access can be removed at any time in Facebook's Settings → Business integrations.

How information is used, stored and shared

  • The authorization token and channel information are stored only on the owner's own computer and are used only to upload the owner's videos and confirm they are published.
  • No information is sold, shared with or disclosed to any third party.
  • No cookies, analytics or tracking are used, by the tool or by this website.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting the locally stored token file removes all stored data. Stored information is deleted once it is no longer needed for publishing.

Changes and contact

Changes to this policy will be posted on this page. Questions can be raised by opening an issue on this site's repository.
